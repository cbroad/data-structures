# data-structures
A Typescript implementation of common data structures. The idea was based on java.util's Collections library, with modifications due to the differences between the two languages and runtimes.  Map and Set structures are functionally compatible with existing JavaScript equivalents.

### Synchronous Collections
- BinaryHeaps
  - MinBinaryHeap (default)
  - MaxBinaryHeap
- BinaryTrees
  <!-- - AVLTree -->
  - BinarySearchTree
  - RedBlackTree
- Lists
  - ArrayList
  - LinkedList
  - OrderedArrayList
- Maps
  - HashMap
  - LinkedHashMap
  - TreeMap
- Sets
  - HashSet
  - LinkedHashSet
  - TreeSet
  
### Asynchronous Collections
  - AsyncStacks
    - ArrayListAsyncStack
    - LinkedListAsyncStack
  - Prioi
